# Формат программного модуля

## Коротко

Формат модуля задает порядок объявления переменных, процедур, функций и исполняемого кода. Встроенный язык допускает русские и английские ключевые слова, комментарии, разные регистры букв и специальные символы, но структура модуля все равно должна быть читаемой и предсказуемой.

## Когда используется

- При оформлении нового модуля.
- При ревью старого кода.
- При ошибках компиляции из-за объявления переменных, расположения процедур или синтаксиса.
- При стандартизации кодстайла команды.

## Как работает

Модуль можно условно делить на три части:

- раздел переменных;
- раздел процедур и функций;
- раздел основной программы.

Не каждый модуль использует все части. Для читаемости лучше явно группировать переменные, экспортные процедуры, внутренние процедуры и обработчики событий. Имена переменных, процедур и функций должны отражать предметный смысл, а не техническую случайность.

## Примеры

```bsl
Перем ТаблицаКэша;

Процедура ИнициализироватьКэш()
    ТаблицаКэша = Новый ТаблицаЗначений;
КонецПроцедуры

ИнициализироватьКэш();
```

Исполняемый код вне процедуры относится к разделу основной программы модуля. Использовать его нужно осторожно, потому что момент выполнения зависит от вида модуля.
