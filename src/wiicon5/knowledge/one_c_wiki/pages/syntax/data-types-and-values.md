# Типы данных и значения

## Коротко

Встроенный язык использует динамическую типизацию: тип имеет значение, а переменная может в разные моменты ссылаться на значения разных типов. Неинициализированная переменная содержит `Неопределено`. Отдельно важно различать `Неопределено`, `NULL` и обычные значения.

## Когда используется

- При проверке параметров процедур и функций.
- При работе с результатами запросов, где может встретиться `NULL`.
- При сериализации, сравнении и преобразовании значений.
- При поиске ошибок из-за неожиданного типа значения.

## Как работает

Тип определяет множество значений и допустимые операции. Переменная хранит ссылку на значение. Для кода это означает:

- тип переменной не фиксируется объявлением;
- одно имя может сначала содержать строку, затем число или объект;
- отсутствие присваивания дает `Неопределено`;
- `NULL` используется как специальное значение, часто связанное с отсутствием значения в данных;
- значения могут быть изменяемыми и неизменяемыми.

Основные базовые типы из главы: `NULL`, `Булево`, `Дата`, `Неопределено`, `Строка`, `Тип`, `Число`.

## Примеры

```bsl
Если ЗначениеЗаполнено(Контрагент) Тогда
    Сообщить(Контрагент);
Иначе
    Сообщить("Контрагент не указан");
КонецЕсли;
```

Проверки значения должны учитывать предметный смысл: `Неопределено`, пустая строка, ноль и `NULL` — разные ситуации.
