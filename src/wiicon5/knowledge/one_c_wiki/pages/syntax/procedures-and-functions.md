# Процедуры и функции

## Коротко

Процедуры и функции — основные единицы структурирования кода во встроенном языке. Процедура выполняет действие, функция должна возвращать значение. Доступность процедуры или функции зависит от модуля, экспорта, контекста и директив компиляции.

## Когда используется

- При выделении повторяемой логики.
- При создании обработчиков событий.
- При проектировании API общего модуля.
- При разделении клиентского и серверного кода.

## Как работает

Процедура или функция имеет имя, параметры и тело. Параметры могут передаваться с учетом особенностей клиент-серверного вызова. Экспорт делает процедуру или функцию доступной из других контекстов, но не отменяет ограничений платформы.

Практические правила:

- функция должна возвращать значение во всех ожидаемых ветках;
- процедуры с побочными эффектами лучше явно называть действием;
- экспортировать нужно только стабильный интерфейс;
- параметры должны быть проверены на допустимые значения и типы;
- клиент-серверный переход должен быть осознанным, а не случайным.

## Примеры

```bsl
Функция РассчитатьСумму(Количество, Цена) Экспорт
    Возврат Количество * Цена;
КонецФункции

Процедура ЗаполнитьИтог(Строка)
    Строка.Сумма = РассчитатьСумму(Строка.Количество, Строка.Цена);
КонецПроцедуры
```
