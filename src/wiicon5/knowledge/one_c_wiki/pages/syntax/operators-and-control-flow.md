# Операторы и управляющие конструкции

## Коротко

Операторы задают действия программы: объявление переменных, создание объектов, условия, циклы, переходы, выполнение фрагментов кода, ожидание асинхронных функций и работа с обработчиками событий. Это основной процедурный слой встроенного языка.

## Когда используется

- При написании любой прикладной логики.
- При выборе между условием, циклом и обходом коллекции.
- При создании объектов встроенного языка.
- При подключении и отключении обработчиков событий.

## Как работает

Ключевые конструкции главы:

- `Перем` — явное объявление переменной;
- `Новый` — создание объекта;
- `Процедура` и `Функция` — именованные блоки кода;
- `Если` — условное выполнение;
- `Для`, `Для каждого`, `Пока` — циклы, подробно см. [Циклы](cycles.md);
- `Прервать`, `Продолжить`, `Возврат` — управление ходом выполнения;
- `Ждать` — ожидание завершения асинхронной функции;
- добавление и удаление обработчиков событий.

## Примеры

```bsl
Для Каждого СтрокаТовара Из Товары Цикл
    Если СтрокаТовара.Количество <= 0 Тогда
        Продолжить;
    КонецЕсли;

    Итог = Итог + СтрокаТовара.Сумма;
КонецЦикла;
```

## Типовые ошибки

- Использовать цикл там, где запрос или динамический список решит задачу эффективнее.
- Делать слишком длинные вложенные условия вместо раннего `Возврат`.
- Создавать объект без понимания, где он будет исполняться: клиент или сервер.
