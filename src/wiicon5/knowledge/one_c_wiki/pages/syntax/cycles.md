# Циклы

Status: `answer-ready`.

## Коротко

Циклы во встроенном языке повторяют блок операторов внутри конструкции `Цикл ... КонецЦикла`. В wiki выделены три вида циклов: счетчик `Для`, обход коллекции `Для каждого` и цикл по условию `Пока`.

## Когда используется

- `Для` — когда нужно выполнить блок известное число раз или пройти диапазон числового счетчика.
- `Для каждого` — когда нужно перебрать элементы коллекции значений.
- `Пока` — когда число повторений заранее неизвестно и зависит от логического условия.

## Цикл `Для`

Синтаксис:

```bsl
Для Индекс = Начало По Конец Цикл
    // Операторы
КонецЦикла;
```

Как работает:

- перед началом цикла переменной-счетчику присваивается начальное значение;
- после каждой итерации счетчик автоматически увеличивается на `1`;
- цикл выполняется, пока счетчик меньше или равен конечному значению;
- условие проверяется перед выполнением тела цикла.

Пример:

```bsl
Для НомерСтроки = 1 По 10 Цикл
    Сообщить("Строка " + НомерСтроки);
КонецЦикла;
```

## Цикл `Для каждого`

Синтаксис:

```bsl
Для Каждого Элемент Из Коллекция Цикл
    // Операторы
КонецЦикла;
```

Как работает:

- на каждой итерации переменная получает очередной элемент коллекции;
- обход продолжается, пока не перебраны все элементы;
- цикл можно завершить досрочно оператором `Прервать`.

Пример:

```bsl
Итог = 0;

Для Каждого СтрокаТовара Из Товары Цикл
    Если СтрокаТовара.Количество <= 0 Тогда
        Продолжить;
    КонецЕсли;

    Итог = Итог + СтрокаТовара.Сумма;
КонецЦикла;
```

## Цикл `Пока`

Синтаксис:

```bsl
Пока Условие Цикл
    // Операторы
КонецЦикла;
```

Как работает:

- перед каждой итерацией вычисляется логическое выражение;
- тело выполняется, пока выражение равно `Истина`;
- если условие изначально ложно, тело цикла не выполняется ни разу.

Пример:

```bsl
Попыток = 0;

Пока Попыток < 3 Цикл
    Попыток = Попыток + 1;
    Если ВыполнитьОперацию() Тогда
        Прервать;
    КонецЕсли;
КонецЦикла;
```

## Управление циклом

- `Прервать` завершает текущий цикл досрочно и передает управление за `КонецЦикла`.
- `Продолжить` завершает текущую итерацию и переходит к следующей проверке/итерации цикла.
- `Возврат` выходит из текущей процедуры или функции, а не только из цикла.

## Когда цикл не лучший выбор

- Если нужно выбрать данные из базы, сначала рассмотреть запрос.
- Если нужно показать список на форме, сначала рассмотреть динамический список.
- Если цикл выполняет много запросов внутри итераций, вероятен риск производительности.
- Если логика цикла глубоко вложена, лучше выделить процедуру/функцию или использовать ранний `Продолжить`/`Возврат`.

## Типовые ошибки

- Использовать `Для` для коллекции вместо `Для каждого`.
- Забыть изменить условие в `Пока` и получить бесконечный цикл.
- Использовать `Продолжить`, ожидая выхода из цикла; для выхода нужен `Прервать`.
- Делать запрос к базе внутри каждой итерации без необходимости.
