# Виды программных модулей

## Коротко

В 1С есть несколько видов программных модулей. Они различаются местом размещения, доступным контекстом, жизненным циклом и тем, кто вызывает их код: платформа, пользовательское действие, объектная модель или другой код.

## Когда используется

- При выборе места для новой процедуры или функции.
- При разборе, где должен жить код: в форме, объекте, менеджере, общем модуле или команде.
- При проектировании API конфигурации через экспортные процедуры общих модулей.

## Как работает

Основные виды из главы 4:

- модуль управляемого приложения — события начала и завершения пользовательского сеанса;
- модуль внешнего соединения — работа через внешнее соединение;
- модуль сеанса — код, связанный с началом серверного сеанса;
- общий модуль — переиспользуемые процедуры и функции;
- модуль прикладного объекта — поведение конкретного объекта данных;
- модуль менеджера объекта — операции уровня менеджера;
- модуль формы — логика пользовательской формы;
- модуль команды — обработка прикладной команды.

Ключевой выбор: код объекта отвечает за поведение объекта, код формы — за интерфейсный сценарий, общий модуль — за переиспользуемую логику, модуль менеджера — за операции уровня типа объекта.

## Примеры

Если нужно проверить заполнение реквизитов перед записью документа, это кандидат в модуль объекта. Если нужно обработать нажатие кнопки на форме, это модуль формы. Если нужно переиспользовать расчет в нескольких местах, это общий модуль.
