# Препроцессор и директивы компиляции

## Коротко

Инструкции препроцессора и директивы компиляции управляют тем, какой код попадет в модуль и где он может исполняться. Это основной механизм разделения клиентского, серверного и других вариантов исполнения во встроенном языке.

## Когда используется

- При разделении кода по клиенту и серверу.
- При создании общих модулей, процедур и функций с ограниченной областью исполнения.
- При адаптации кода под разные варианты запуска системы.
- При анализе ошибок доступности методов и объектов в конкретном клиенте или на сервере.

## Как работает

Глава различает два механизма:

- инструкции препроцессора действуют на исходный текст модуля;
- директивы компиляции действуют на структурные единицы кода: процедуры, функции и объявления переменных.

Практический смысл: часть кода может быть исключена до компиляции для конкретного варианта исполнения, а часть может быть скомпилирована только для заданной стороны выполнения.

## Примеры

```bsl
&НаСервере
Функция ПолучитьДанныеДляФормы()
    Возврат Новый Структура;
КонецФункции

&НаКлиенте
Процедура ОбновитьФорму()
    Данные = ПолучитьДанныеДляФормы();
КонецПроцедуры
```

Такой код явно показывает границу: получение данных выполняется на сервере, обновление интерфейса — на клиенте.

## Типовые ошибки

- Ставить директиву формально, не проверяя фактический контекст доступных объектов.
- Вызывать клиентский код из серверной процедуры.
- Дублировать логику вместо выделения чистой серверной функции и тонкого клиентского обработчика.
