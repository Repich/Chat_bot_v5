# Управляемые блокировки

## Коротко

Управляемые блокировки дают разработчику более явный контроль над блокированием данных в прикладной логике. Они нужны, когда автоматического поведения платформы недостаточно для корректной конкурентной работы.

## Когда используется

- При сложной логике записи и проведения.
- Когда нужно заблокировать данные по прикладному ключу.
- При переходе конфигурации к режиму управляемых блокировок.

## Как работает

Разработчик задает область блокировки и режим. Важно блокировать минимально достаточные данные и делать это в правильной транзакционной границе.

## Типовые ошибки

- Блокировать больше данных, чем нужно.
- Устанавливать блокировку без явного понимания транзакции.
- Исправлять конфликт блокировкой вместо пересмотра модели данных.
