# Работа с данными

## Коротко

Глава описывает runtime-механизмы работы с данными: транзакции, блокировки, монопольный режим, индексы и динамические выборки. Это слой, который определяет надежность, конкурентность и производительность прикладного кода.

## Когда используется

- При записи и изменении данных в прикладной логике.
- При проектировании операций, которые должны быть атомарными.
- При анализе конфликтов записи, блокировок и конкурентной работы пользователей.
- При оптимизации чтения больших наборов данных.

## Как работает

Платформа управляет целостностью данных через транзакции и блокировки. Разработчик может явно открывать транзакции, но должен учитывать вложенность, влияние на программные объекты и режимы блокировок. Для чтения данных важны динамические выборки и индексы метаданных.

Основные блоки главы:

- механизм транзакций;
- явный и вложенный вызов транзакций;
- объектные и управляемые блокировки;
- пессимистическая и оптимистическая блокировка;
- режимы блокировок в конфигурации;
- монопольный режим;
- индексы объектов метаданных;
- динамические выборки данных.

## Примеры

Если код записывает несколько связанных объектов, эти изменения часто нужно объединять в одну транзакцию. Но длинная транзакция повышает риск блокировок, поэтому границы транзакции должны быть минимальными и осознанными.
