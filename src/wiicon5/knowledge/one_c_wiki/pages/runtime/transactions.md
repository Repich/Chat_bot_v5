# Транзакции

## Коротко

Транзакция объединяет несколько операций с данными в атомарный блок: либо все изменения фиксируются, либо откатываются. Это базовый механизм целостности данных.

## Когда используется

- При записи нескольких связанных объектов.
- При проведении документов и формировании движений.
- При операциях, где нельзя оставить данные в промежуточном состоянии.

## Как работает

Код может явно начинать и завершать транзакции. Вложенные вызовы требуют аккуратности: важно понимать, где реально фиксируется результат и как ошибки влияют на откат.

## Типовые ошибки

- Держать транзакцию слишком долго.
- Выполнять пользовательский ввод внутри транзакции.
- Перехватывать исключение и не откатывать нарушенное состояние.
