# Соединения и вложенные запросы

## Коротко

Соединения связывают несколько источников данных в одном запросе. Вложенные запросы позволяют предварительно подготовить набор данных для дальнейшей выборки.

## Когда используется

- При объединении данных из справочников, документов и регистров.
- При сравнении основного набора с дополнительной аналитикой.
- Когда один запрос должен использовать результат другого.

## Как работает

В языке запросов есть внутренние и внешние соединения. Тип соединения определяет, какие строки попадут в результат при наличии или отсутствии соответствия между источниками. Вложенный запрос работает как источник данных для внешнего запроса.

## Типовые ошибки

- Использовать внешнее соединение без понимания появления пустых значений.
- Соединять источники по неиндексируемым или неоднозначным полям.
- Делать вложенный запрос вместо временной таблицы там, где нужен повторный доступ к промежуточному результату.
