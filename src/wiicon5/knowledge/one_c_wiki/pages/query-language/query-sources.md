# Источники данных запроса

## Коротко

Источник данных запроса — таблица или виртуальное представление данных, к которому обращается язык запросов 1С. Источники формируются платформой по объектам конфигурации и их данным.

## Когда используется

- При написании запроса.
- При выборе между таблицей объекта, табличной частью и виртуальной таблицей.
- При оптимизации чтения данных из регистров.

## Как работает

Запрос обращается не напрямую к произвольной SQL-таблице, а к источникам, которые предоставляет платформа: справочникам, документам, регистрам, табличным частям и виртуальным таблицам. У каждого источника есть поля и ограничения.

## Типовые ошибки

- Считать виртуальную таблицу обычной физической таблицей.
- Читать все поля и строки без отбора.
- Не учитывать параметры виртуальных таблиц регистров.
