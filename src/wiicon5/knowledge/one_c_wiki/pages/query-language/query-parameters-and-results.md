# Параметры и результат запроса

## Коротко

Параметры запроса передают значения в текст запроса безопасно и управляемо. Результат запроса затем обходится или выгружается в структуру данных для дальнейшей обработки.

## Когда используется

- При фильтрации по датам, ссылкам, организациям и другим значениям.
- При многократном выполнении одного текста запроса с разными условиями.
- При передаче результата в отчет, форму или обработку.

## Как работает

В тексте запроса используются имена параметров, а значения задаются объекту запроса перед выполнением. Результат можно обходить выборкой или выгружать, в зависимости от сценария и объема данных.

## Типовые ошибки

- Склеивать текст запроса со значениями строками вместо параметров.
- Выгружать слишком большой результат в память.
- Не проверять типы параметров.
