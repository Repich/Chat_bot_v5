# Структура языка запросов

## Коротко

Язык запросов 1С описывает выборку данных: поля, источники, соединения, условия, группировки, итоги, сортировку и временные таблицы.

## Когда используется

- При чтении данных из информационной базы.
- При подготовке наборов данных для отчетов и СКД.
- При построении сложной выборки с условиями и группировками.

## Как работает

Запрос состоит из секций. Базовая логика: выбрать поля из источников, связать источники, ограничить строки, сгруппировать, рассчитать агрегаты, отсортировать и вернуть результат.

## Типовые ошибки

- Делать бизнес-логику в циклах вместо запроса.
- Смешивать слишком много задач в одном нечитаемом запросе.
- Не использовать параметры запроса.
