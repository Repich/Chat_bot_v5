# Работа с запросами

## Коротко

Глава описывает язык запросов 1С и выполнение запросов к данным информационной базы. Это отдельный язык внутри платформы со своими источниками данных, секциями, соединениями, временными таблицами, выражениями, агрегатами и особенностями работы с виртуальными таблицами.

## Когда используется

- При выборке данных из справочников, документов, регистров и других таблиц платформы.
- При построении отчетов, обработок, форм списков и аналитики.
- При работе с временными таблицами, пакетными запросами и соединениями.
- При оптимизации чтения данных и подготовке наборов данных для СКД.

## Как работает

Запрос описывает, какие данные нужно получить, из каких источников, с какими условиями, группировками, соединениями и сортировкой. В 1С источниками являются таблицы, сформированные платформой по метаданным, включая виртуальные таблицы регистров и другие специальные источники.

Основные блоки главы:

- источники данных запросов;
- виртуальные и обычные поля;
- синтаксис языка запросов;
- секции запроса и описание выборки;
- соединения, вложенные запросы и временные таблицы;
- условия, группировки, итоги, сортировка;
- параметры запроса;
- выполнение запроса и обработка результата;
- особенности запросов к различным объектам метаданных.

## Примеры

Типовой проектный выбор: для простого списка можно использовать динамический список, а для сложной аналитики лучше явно проектировать запрос или схему компоновки данных.

Типовой риск: воспринимать виртуальную таблицу как обычную физическую таблицу. Ее поведение задается платформой и параметрами обращения.
