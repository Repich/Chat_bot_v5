# Временные таблицы

## Коротко

Временная таблица хранит промежуточный результат внутри пакетного выполнения запроса. Она помогает разбивать сложную выборку на этапы.

## Когда используется

- При сложной аналитике.
- Когда промежуточный результат используется несколько раз.
- Когда запрос становится слишком большим и нечитаемым.

## Как работает

Один запрос создает временную таблицу, следующий использует ее как источник. Временная таблица живет в рамках контекста выполнения запроса или менеджера временных таблиц.

## Типовые ошибки

- Использовать временные таблицы для простых выборок без необходимости.
- Не очищать или переиспользовать временный контекст неосознанно.
