# Интерфейс Такси

## Коротко

`Такси` — современная модель интерфейса 1С с акцентом на разделы, команды, рабочую область, глобальный поиск, уведомления и сервисные действия. Для разработчика это целевая модель размещения пользовательских функций.

## Когда используется

- При разработке управляемого приложения.
- При настройке видимости разделов и команд.
- При проектировании навигации для пользователей.

## Как работает

Интерфейс `Такси` организует пользовательскую работу через основное окно, панели и меню. Состав видимых команд и разделов формируется метаданными, правами, функциональными опциями и пользовательскими настройками.

## Типовые ошибки

- Дублировать команды в разных местах без понятного пользовательского сценария.
- Не проверять видимость команд под ролями реальных пользователей.
