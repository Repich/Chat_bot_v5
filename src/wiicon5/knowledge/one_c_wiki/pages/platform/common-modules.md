# Общие модули

## Коротко

Общий модуль хранит переиспользуемые процедуры и функции. Его поведение определяется свойствами модуля: доступность на клиенте, сервере, внешнем соединении, вызов сервера и повторное использование возвращаемых значений.

## Когда используется

- При выделении общей бизнес-логики.
- При создании API для нескольких объектов, форм и обработок.
- При разделении клиентской и серверной логики.

## Как работает

Общий модуль не привязан к конкретному объекту данных. Его экспортные процедуры и функции могут вызываться из других модулей, если это разрешено свойствами и контекстом. Важно не превращать общий модуль в свалку несвязанных функций.

## Типовые ошибки

- Помещать в общий модуль код, зависящий от конкретной формы.
- Экспортировать внутренние функции без стабильного назначения.
- Игнорировать клиент-серверные свойства общего модуля.
