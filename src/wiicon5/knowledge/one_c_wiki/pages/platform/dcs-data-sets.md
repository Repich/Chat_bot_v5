# Наборы данных СКД

## Коротко

Набор данных СКД описывает источник строк для компоновки. Он может строиться на запросе, объекте или объединении и определяет поля, доступные схеме.

## Когда используется

- При создании отчета с одним или несколькими источниками.
- При связывании данных из разных наборов.
- При подготовке вычисляемых полей и ресурсов.

## Как работает

Набор данных предоставляет поля. Несколько наборов могут связываться между собой. Для запроса в СКД используется язык запросов и его расширения для компоновки.

## Типовые ошибки

- Смешивать бизнес-расчет и представление отчета в одном запросе без необходимости.
- Не задавать связи между наборами явно, когда данные должны объединяться по ключам.
