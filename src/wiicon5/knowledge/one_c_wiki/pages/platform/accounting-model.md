# Модель бухгалтерского учета

## Коротко

Бухгалтерская модель 1С строится на планах счетов, регистрах бухгалтерии, аналитике, видах учета и записях движений. Она нужна, когда конфигурация должна отражать хозяйственные операции по счетам.

## Когда используется

- При проектировании бухгалтерской подсистемы.
- При разработке документов, формирующих бухгалтерские движения.
- При настройке аналитик и видов учета.

## Как работает

План счетов задает структуру счетов. Регистр бухгалтерии хранит движения. Документы или иной код формируют наборы записей, которые отражают операции по счетам и аналитикам.
