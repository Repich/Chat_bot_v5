# Бухгалтерский учет

## Коротко

Глава описывает платформенные механизмы бухгалтерского учета: планы счетов, аналитический учет, виды учета, регистры бухгалтерии и записи регистров. Это прикладной слой метаданных для конфигураций, где нужна бухгалтерская модель.

## Когда используется

- При проектировании бухгалтерских подсистем.
- При создании планов счетов и регистров бухгалтерии.
- При настройке аналитического и консолидированного учета.
- При разработке документов, которые формируют бухгалтерские движения.

## Как работает

Бухгалтерский учет в платформе строится вокруг плана счетов и регистра бухгалтерии. План счетов задает структуру счетов, признаки и аналитику. Регистр бухгалтерии хранит записи, которые отражают движения по счетам и измерениям учета.

Основные блоки главы:

- обзор механизма бухгалтерского учета;
- планы счетов;
- аналитический учет;
- виды учета;
- записи и наборы записей регистров бухгалтерии;
- консолидированный учет;
- создание плана счетов;
- свойства регистра бухгалтерии.

## Примеры

Если документ должен отражать хозяйственную операцию в бухгалтерском учете, его проведение обычно формирует записи регистра бухгалтерии, связанные с планом счетов и аналитикой.
