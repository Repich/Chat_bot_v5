# Конфигурация базы данных и реструктуризация

## Коротко

Конфигурация и конфигурация базы данных — разные состояния. Разработчик меняет конфигурацию, но для применения изменений к информационной базе нужно обновление конфигурации базы данных, иногда с реструктуризацией данных.

## Когда используется

- После изменения объектов метаданных, влияющих на структуру хранения.
- При обновлении информационной базы.
- При оценке рисков монопольного доступа, блокировок и длительных операций.

## Как работает

Обновление конфигурации базы данных приводит структуру хранения в соответствие с метаданными. Если изменения затрагивают таблицы, поля, индексы или связи, платформа выполняет реструктуризацию. Для некоторых операций требуется монопольный доступ или завершение активных сеансов.

## Типовые ошибки

- Считать сохранение конфигурации применением изменений к базе.
- Запускать реструктуризацию без оценки длительности и влияния на пользователей.
- Игнорировать сценарии динамического и фонового обновления.
