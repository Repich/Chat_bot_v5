# Структура интерфейса приложения

## Коротко

Интерфейс приложения состоит из основного окна, вспомогательных окон, панелей разделов, навигации, действий, системных команд и информационных областей. Он связывает метаданные с пользовательской навигацией.

## Когда используется

- При проектировании пользовательского сценария.
- При решении, где должна быть доступна команда или форма.
- При настройке основного окна, вспомогательных окон и панелей.

## Как работает

Платформа строит интерфейс из подсистем, команд, форм и настроек. Пользователь видит не дерево метаданных, а прикладную навигацию: разделы, команды, списки, формы, избранное, историю и поиск.

## Типовые ошибки

- Проектировать метаданные без пользовательского маршрута.
- Добавлять объект в конфигурацию, но не включать его в подходящую подсистему и командный интерфейс.
