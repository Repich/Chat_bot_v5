# Динамический список

## Коротко

Динамический список — специальный механизм формы для отображения и получения списочных данных. Он умеет читать данные порциями, кешировать их и использовать настройки, близкие к запросам и СКД.

## Когда используется

- В формах списков.
- Для больших наборов данных.
- Когда нужен поиск, отбор, оформление и порционная загрузка.

## Как работает

Динамический список получает данные из основной таблицы или произвольного запроса. Платформа управляет чтением порций, кешированием, отображением и поиском. Разработчик может настраивать получение данных и дополнительную обработку.

## Типовые ошибки

- Заменять динамический список ручной загрузкой всей таблицы.
- Делать тяжелую обработку данных на клиенте.
- Не учитывать режим кеширования и объем отображаемых записей.
