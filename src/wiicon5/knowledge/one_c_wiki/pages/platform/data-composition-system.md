# Система компоновки данных

## Коротко

Система компоновки данных (СКД) используется для построения отчетов и аналитических представлений на основе схемы, наборов данных, ресурсов, группировок, параметров и пользовательских настроек. Это платформенный механизм над запросами и источниками данных.

## Когда используется

- При создании отчетов.
- При построении гибких аналитических форм, где пользователю нужны настройки отбора, группировки и оформления.
- При работе с наборами данных из запросов, объектов и объединений.
- При разделении схемы отчета, настроек по умолчанию и пользовательских вариантов.

## Как работает

СКД опирается на схему компоновки данных. В ней описываются источники данных, наборы данных, связи, вычисляемые поля, ресурсы, параметры, макеты и настройки. Затем компоновщик использует схему и настройки, чтобы сформировать результат.

Основные блоки главы:

- общие сведения о компоновке данных;
- поля, параметры и свойства использования;
- схема компоновки данных;
- источники и наборы данных;
- связи наборов данных;
- вычисляемые поля и ресурсы;
- расширение языка запросов для СКД;
- язык выражений СКД;
- настройки, варианты, макеты и вывод результата.

## Примеры

Если отчет должен позволять пользователю менять группировки и отборы без изменения кода, СКД обычно предпочтительнее ручного формирования табличного документа.
