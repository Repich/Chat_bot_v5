# Командная модель

## Коротко

Командная модель описывает действия, которые пользователь может выполнить из интерфейса: стандартные команды, глобальные команды, навигационные команды, команды действия и команды объектов.

## Когда используется

- При проектировании пользовательских действий.
- При связывании формы, объекта и команды.
- При настройке командного интерфейса разделов.

## Как работает

Команды формируются платформой и конфигурацией. Стандартные команды появляются для типовых действий, прикладные команды задает разработчик. Параметризуемые команды получают контекст, например выбранный объект или текущую форму.

## Типовые ошибки

- Делать кнопку формы вместо общей команды, если действие должно быть доступно из разных мест.
- Не различать навигационную команду и команду действия.
