# Дерево объектов конфигурации

## Коротко

Дерево объектов конфигурации — основная навигация по метаданным в конфигураторе. Через него разработчик создает, удаляет и настраивает объекты, а также видит структуру прикладного решения.

## Когда используется

- При проектировании состава конфигурации.
- При поиске объекта метаданных и его подчиненных объектов.
- При анализе ссылок на объект перед удалением или изменением.

## Как работает

Дерево группирует объекты по типам: справочники, документы, отчеты, обработки, регистры, общие объекты и другие ветви. Для каждого объекта доступны свойства, формы, команды, модули, макеты и другие зависимые сущности, если они применимы к данному типу.

## Типовые ошибки

- Удалять объект без проверки ссылок на него.
- Искать поведение объекта только в свойствах, забывая про модуль объекта, модуль менеджера, формы и команды.
