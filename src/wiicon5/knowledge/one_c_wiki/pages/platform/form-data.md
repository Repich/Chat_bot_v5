# Данные формы

## Коротко

Данные формы — это представление данных для интерфейса, а не сам прикладной объект. Управляемая форма работает с реквизитами формы и преобразованием данных между формой и объектами.

## Когда используется

- При разработке управляемых форм.
- При сохранении изменений из формы в объект.
- При разделении клиентской логики формы и серверной бизнес-логики.

## Как работает

Форма содержит реквизиты. Часть реквизитов связана с данными объекта, часть служит только интерфейсной логике. Для прикладных объектов используется преобразование данных объекта в данные формы и обратно.

## Типовые ошибки

- Считать реквизит формы самим реквизитом объекта.
- Изменять данные формы и ожидать автоматическую запись объекта без явной логики сохранения.
