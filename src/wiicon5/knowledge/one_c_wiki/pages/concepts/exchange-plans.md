# Планы обмена

## Коротко

План обмена описывает узлы и правила обмена данными между информационными базами или участниками распределенной системы.

## Когда используется

- При синхронизации данных между базами.
- В распределенных информационных базах.
- Когда нужно отслеживать, какие данные должны быть переданы конкретному узлу.

## Как работает

План обмена задает структуру узлов и участвует в регистрации изменений. Конкретный механизм обмена строится вокруг сообщений, правил, состава данных и обработки изменений.

## Типовые ошибки

- Проектировать обмен как разовую выгрузку без учета дальнейших изменений.
- Не определить владельца данных и правила разрешения конфликтов.
