# Объекты конфигурации: обзор

## Коротко

Глава 5 описывает основные объекты конфигурации и их свойства: общие объекты, справочники, документы, журналы, перечисления, отчеты, обработки, планы, регистры, бизнес-процессы и задачи. Это большой справочник по метаданным платформы.

## Когда используется

- При выборе правильного объекта метаданных для прикладной задачи.
- При проектировании структуры данных и поведения прикладного решения.
- При настройке форм, команд, прав, общих модулей и подсистем.
- При анализе того, какие объекты создают типы, таблицы, менеджеры, формы и программные модули.

## Как работает

Объекты конфигурации задают прикладную модель решения. Часть объектов описывает данные, часть - поведение, интерфейс, права, интеграционные и общие механизмы. Многие объекты порождают встроенные типы, менеджеры, формы, команды и программные контексты.

Крупные блоки главы:

- свойства конфигурации;
- модули приложения, внешнего соединения и сеанса;
- ветвь `Общие`: подсистемы, общие модули, параметры сеанса, роли, стили, языки, хранилища настроек;
- справочники, документы, журналы документов, перечисления;
- отчеты и обработки;
- планы видов характеристик, планы счетов, планы обмена;
- регистры сведений, накопления, бухгалтерии и расчета;
- бизнес-процессы и задачи.

## Примеры

Если нужно хранить список контрагентов, базовый кандидат - справочник. Если нужно фиксировать хозяйственное событие с движениями по регистрам, базовый кандидат - документ. Если нужно хранить накопленные итоги, нужен регистр накопления, а не произвольная таблица.
