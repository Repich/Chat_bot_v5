# Справочники

## Коротко

Справочник хранит список однотипных прикладных сущностей: контрагентов, номенклатуру, склады, подразделения и другие классификаторы. Это один из базовых объектов конфигурации.

## Когда используется

- Когда нужно хранить относительно устойчивый список объектов.
- Когда элемент должен иметь реквизиты, табличные части, формы и ссылочный тип.
- Когда данные используются в документах, регистрах и отчетах как аналитика.

## Как работает

Справочник задает метаданные списка. Платформа предоставляет менеджер справочника, элементы, группы, формы списка/элемента, стандартные команды и ссылочный тип. Иерархия и владельцы зависят от настроек конкретного справочника.

## Типовые ошибки

- Делать справочник для событий, которые должны быть документами.
- Использовать строковые поля вместо ссылок на элементы справочника.
