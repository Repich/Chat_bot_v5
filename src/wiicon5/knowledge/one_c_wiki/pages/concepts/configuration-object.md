# Объект конфигурации

## Коротко

`Объект конфигурации` — элемент конфигурации, через который описываются данные, поведение, интерфейс или служебные механизмы прикладного решения.

Через объекты конфигурации платформа дает разработчику предметные строительные блоки: справочники, документы, регистры, отчеты, обработки, планы видов, бизнес-процессы и другие элементы.

## Когда используется

- При проектировании структуры данных.
- При выборе механизма для новой функциональности.
- При объяснении, где должен жить код: в модуле объекта, форме, общем модуле или другом элементе.

## Основные группы

- Данные и классификаторы: константы, справочники, перечисления.
- Операционные события: документы, журналы документов.
- Аналитика и действия: отчеты и обработки.
- Учетные модели: планы счетов, планы видов характеристик, планы видов расчета.
- Обмен и процессы: планы обмена, бизнес-процессы, задачи.
- Хранение итогов и движений: регистры.
- Общие механизмы: специализированные объекты ветви `Общие`.
