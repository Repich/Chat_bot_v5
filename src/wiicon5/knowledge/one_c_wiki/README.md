# Wiki Язык 1С

Вспомогательная LLM-maintained wiki по языку разработки 1С и связанным механизмам платформы `1С:Предприятие 8.3.27`.

## Цель

- Сформировать удобную базу знаний для ответов на вопросы по разработке на 1С.
- Не заменять официальную документацию, а создавать слой навигации, синтеза, связей и практических пояснений.
- Поддерживать wiki как компилируемый артефакт: новые источники постепенно уточняют существующие страницы.

## Слои

- `raw/` — манифесты и metadata о неизменяемых исходниках; защищенные полные тексты хранятся вне Nextcloud в runtime.
- `sources/` — реестр источников, ссылок, статуса доступа и ingest-решений.
- `pages/` — wiki-страницы по понятиям, синтаксису, runtime, запросам и платформенным механизмам.
- `index.md` — навигационный каталог wiki.
- `viewer.html` — локальный self-contained HTML-просмотрщик wiki.
- `log.md` — хронологический журнал ingest/query/lint действий.
- `AGENTS.md` — schema и правила работы агента с этой wiki.

## Просмотр

- Открыть HTML-просмотрщик: `viewer.html`.
- Пересобрать HTML после изменений: `python3 tools/build_viewer.py`.
- Просмотрщик работает как локальный файл без сервера и внешних CDN.

## Ограничения

- Не использовать учетные данные ITS без явного подтверждения.
- Не выкачивать официальную документацию или книги целиком без отдельного решения по лицензиям, объему и месту хранения.
- Не хранить защищенные полные тексты, cookies, session-state или пароли в дереве проекта.
- Не смешивать этот проект с production-скриптами WorkAssistant4.0.
