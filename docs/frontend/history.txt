5.0.0-alpha.39
- Added a human-readable Workbench summary panel above raw JSON results.
- Skill catalogs, skill cards, drafts, candidates, metadata objects, lifecycle results, and regression replay now render concise business/technical cards.
- Added Workbench actions to open a specific skill, draft, or metadata object by id/full_name.

5.0.0-alpha.38
- Added Skill Workbench controls for skill lifecycle actions: promote, rollback, deprecate, and block.
- Added a web control to run regression replay from the Workbench settings panel.
- Lifecycle actions can now include a reason, regression case ids, target status, successful run count, and explicit admin approval flag.

5.0.0-alpha.32
- Added Workbench controls for agent-generated query synthesis candidates.
- The web client can load the synthesis candidate queue, create a draft from a selected candidate, reject a candidate, or ignore similar generated queries.

5.0.0-alpha.31
- Added Skill Workbench controls to load onboarding candidates, create a draft from a selected candidate, and reject a candidate.

5.0.0-alpha.29
- Added Workbench controls for approval comments plus explicit approve/reject actions.
- Workbench candidate publication now sends approval comments through the admin API.

5.0.0-alpha.13
- Fixed the training banner layout so a completed onboarding message no longer consumes the main viewport.
- Expanded the chat area to use the available screen width and height.
- Moved refresh, backend/frontend history, onboarding launch, and ProductRef controls into a collapsible settings panel.
- Added a visible sessions list that combines browser-saved session ids with sessions currently held by the server process.
- Added a new-session action in the sidebar.

5.0.0-alpha.11
- Added initial-training status banner to the web client.
- Added an admin block for configuration dump path, onboarding launch, and training counters.
- Added polling for background onboarding status so the page updates after training finishes.

5.0.0-alpha.6
- Added Enter-to-send in the chat input; Shift+Enter still inserts a new line.
- Added unread assistant/error notification by blinking the browser tab title while the tab/window is not active.
- The unread title indicator clears when the browser tab becomes visible or focused.
