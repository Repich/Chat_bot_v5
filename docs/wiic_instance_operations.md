# Эксплуатация WIIC-Экземпляра

## Запуск

Выделенный профиль находится в `bot_instances/wiic_bwiki` и по умолчанию запускается на порту `7786`:

```bash
python3 scripts/run_wiic_bwiki.py
```

Windows:

```cmd
scripts\run_wiic_bwiki.cmd
```

Web-клиент:

```text
http://ms-1cmonitor:7786/
```

Windows offline installer использует рабочий каталог
`C:\Monitoring\WiiconChatBot_5`. Сервис слушает все интерфейсы, а локальный
health-check продолжает обращаться к `127.0.0.1:7786`.

Навыки, onboarding, knowledge snapshots и runs этого экземпляра отделены от `local`. Порт MCP задается обычной переменной `WIICON5_MCP_URL`; пока целевая база не подключена, вопросы о данных могут завершаться диагностическим отказом, но ответы по загруженной документации работают независимо от MCP.

## Синхронизация BWiki

Корневая страница и параметры источника заданы в `bot_instances/wiic_bwiki/bot.yaml`:

```text
https://bwiki.beeline.ru/spaces/BRIT/pages/177957241/1C+WIIC
```

Предпочтительный production-вариант — отдельный read-only bearer token в переменной среды:

```env
WIICON5_KNOWLEDGE_BEARER_TOKEN=...
```

Если Confluence поддерживает только сессионную авторизацию, временно можно передать cookie через локальную переменную процесса:

```env
WIICON5_KNOWLEDGE_COOKIE=...
```

Cookie нельзя добавлять в `bot.yaml`, Git, диагностические файлы или сообщения. Для постоянного сервера следует использовать техническую read-only учетную запись или token.

Запустить синхронизацию:

```bash
python3 scripts/sync_wiic_bwiki.py
```

Посмотреть состояние:

```bash
python3 scripts/sync_wiic_bwiki.py --status
```

При отсутствии REST-авторизации можно импортировать локальный JSON-экспорт Confluence:

```bash
python3 scripts/sync_wiic_bwiki.py --input-json /path/to/wiic-pages.json
```

Если доступ есть только в авторизованной вкладке, выполните содержимое
`scripts/bwiki_browser_export.js` в консоли разработчика на корневой странице.
Скрипт обращается к same-origin REST с текущей браузерной сессией, не читает
cookies и скачивает JSON локально. Полученный файл импортируется командой выше.

Или каталог HTML/Markdown:

```bash
python3 scripts/sync_wiic_bwiki.py --input-dir /path/to/wiic-export
```

## Откат Документации

Список снимков выводится командой `--status`. Переключение не удаляет новый снимок:

```bash
python3 scripts/sync_wiic_bwiki.py --activate snapshot_...
```

То же доступно во вкладке `База знаний` в сворачиваемом блоке управления снимками.

## Проверка После Загрузки

1. Открыть `База знаний` и убедиться, что количество страниц больше нуля.
2. Найти несколько терминов WIIC и открыть исходные страницы BWiki.
3. Задать вопрос «как сделать» и проверить ссылки, дату и отсутствие вызова MCP в trace.
4. Задать вопрос о текущих данных и проверить, что документация не подменяет запрос к базе.
5. Проверить старый и новый документы по одной теме: агент должен предупредить о расхождении или устаревании.
